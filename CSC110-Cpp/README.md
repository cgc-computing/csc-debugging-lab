# CSC110 — Introduction to Computer Science (C++)

**Language:** C++17, compiled with `g++ -std=c++17 -Wall` (any recent GCC or Clang; Apple clang on
macOS, MinGW or WSL on Windows). Each activity is a single `.cpp` file; the two Module 14
activities also ship a small data file, `scores.txt`.

## Using these activities in the Work Lab

Each module folder holds one to three short programs (`debug01`, `debug02`, `debug03`, in
increasing difficulty) that are tied to the concept you are studying that week. Every program is
meant to work but does not. Open the activity's `README.md`, read the Expected Behavior, compile
and run the program with the sample input, and compare. Then read the code, find the mistake, fix
it, and — most importantly — be ready to explain to your group *why* the original version behaved
the way it did. The bugs are small and realistic, not typos; understanding the module concept is
what lets you fix them with confidence. Start with `debug01` and move on when your group agrees on
the explanation.

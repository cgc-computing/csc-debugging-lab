# CSC240 — Introduction to Programming Languages: Debugging Activities

CSC240 introduces students who already know Java (CSC110/CSC205) to four new languages in turn: **C**, **C++**, **Scheme**, and **Prolog**. The debugging activities for the weekly CS Work Lab are organized by language and then by course module. Each activity is one short program with a bug rooted in that module's concept; students run it, compare it with the stated Expected Behavior, and fix it while being able to explain why the original misbehaved.

| Language | Tooling | Modules | Activities | Index |
|---|---|---|---|---|
| C | `gcc -std=c11 -Wall` (ASan for two activities) | 3 | 8 | [`C/README.md`](C/README.md) |

Solutions, corrected sources, and validation logs live in each language's `_solutions/` folder.

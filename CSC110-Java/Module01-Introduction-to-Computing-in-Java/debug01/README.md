# Quotation Printer

**Course:** CSC110 &nbsp;|&nbsp; **Module 1:** Introduction to Computing in Java &nbsp;|&nbsp; **Activity:** debug01
**Language:** Java 17+

## Goal

This program prints a title, an underline, and a four-line quotation, with the author's name on its own line at the end.

## Expected Behavior

The program takes no input. A correct run prints exactly this:

```
A Favorite Quotation
--------------------
Do not go where the path may lead;
go instead where there is no path
and leave a trail.
      -- Ralph Waldo Emerson
```

## How to Run

```bash
javac QuotePrinter.java
java QuotePrinter
```

## Your Task

Run the program and compare its output, character by character, with the Expected Behavior above. This program contains one or more bugs. Fix them so the program matches the Expected Behavior, and be ready to explain *why* the original version behaved the way it did. Do not rewrite the program; the structure is fine.

## Think About

- How many lines of output do you see, and how many should there be?
- Java has more than one statement for sending text to the screen. What is the difference between them?
- After a line of text is printed, what decides whether the *next* text starts on a new line?

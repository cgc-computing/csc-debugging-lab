# CSC110 — Introduction to Computer Science (Java)

**Language:** Java 17 or newer (compile with `javac`, run with `java`; any JDK 17+ works)

These are short debugging activities for the weekly **CS Work Lab**. Each activity is a small,
realistic Java program that does not quite do what its README says it should. Pick the module you
are currently studying, open an activity folder, read its `README.md`, compile and run the program
with the sample input, and compare what you see with the Expected Behavior. Then read the code,
find the problem, fix it, and — most importantly — be ready to explain *why* the original version
behaved the way it did. Activities are numbered `debug01`, `debug02`, `debug03` in increasing
difficulty within each module; `debug01` should take about 10–15 minutes, later ones longer. Work
in pairs or small groups and talk through the "Think About" questions before you change any code.

# Welcome Greeting

**Course:** CSC101 &nbsp;|&nbsp; **Module 1:** Introduction to Computers and Python &nbsp;|&nbsp; **Activity:** debug01  
**Language:** Python 3

## Goal

The program greets the user, asks for their name and favorite color, and prints a friendly
welcome message that uses both answers.

## Expected Behavior

```
Welcome to CSC101!
Let's get to know each other.
What is your name? Jordan
What is your favorite color? blue

Nice to meet you, Jordan.
I like the color blue too!
Have a great semester.
```

## How to Run

```bash
python3 greeting.py
```

When prompted, type `Jordan` and press Enter, then type `blue` and press Enter.

## Your Task

Run the program and read everything Python prints, from the first line to the last. This program
contains one or more bugs. Fix them so the program matches the Expected Behavior, and be ready to
explain *why* the original version behaved the way it did. Do not rewrite the program; the structure
is fine.

## Think About

* Python printed several lines and *then* stopped. What does that tell you about how Python runs a
  program?
* The last message Python prints is called a traceback. Which parts of it tell you *where* to look,
  and which part tells you *what* the problem was?
* Python treats `name` and `Name` as two different things. Why might that matter here?

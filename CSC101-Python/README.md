# CSC101 — Introduction to Computer Science (Python) — Debugging Activities

**Course:** CSC101 Introduction to Computer Science  
**Language / tooling:** Python 3 (tested with Python 3.9; any Python 3.9+ works). Run programs
from a terminal with `python3 program.py`, or open them in IDLE / VS Code / Thonny.

## How to use these in the CS Work Lab

Pick the module you are currently studying and open one of its `debugXX` folders. Each folder holds
a short, realistic program and a `README.md` that describes what the program is *supposed* to do,
gives a sample run, and tells you exactly how to run it. Run the program with the sample input,
compare what you see with the Expected Behavior, then read the code and find out why. Activities are
numbered by difficulty within a module (`debug01` is the quickest). Work in pairs or small groups,
and when you have a fix, make sure you can explain *why* the original behaved the way it did — that
explanation is the point of the exercise, not the fix itself.
